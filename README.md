# 🥗 NutriFy

> Your smart nutrition companion for healthier living.

NutriFy is a modern health and nutrition platform designed to help users track meals, monitor nutrition intake, and maintain a healthy lifestyle. The application provides personalized insights, smart recommendations, and an easy-to-use interface for managing daily nutrition goals.

---

# ✨ Features

* 🍎 Track daily meals and calorie intake
* 📊 Nutrition analysis with detailed insights
* 🤖 AI-powered food recommendations
* 📅 Daily and weekly diet tracking
* 🔐 Secure authentication and user profiles
* 📱 Responsive and user-friendly interface
* 📈 Progress monitoring and health statistics
* 🌍 Accessible anytime, anywhere

---

# 🚀 Getting Started

## Prerequisites

Make sure you have installed:

* Node.js
* npm or yarn
* MongoDB

---

## Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/NutriFy.git
```

### 2️⃣ Navigate to the project directory

```bash
cd NutriFy
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Setup environment variables

Create a `.env` file in the root directory and add:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### 5️⃣ Start the development server

```bash
npm start
```
